### Descrição

O **kind version** exibe a versão instalada do Kind, bem como a arquitetura do S.O.

---

### Sintaxe

kind **version** [OPTIONS]

---

### Opções

As opções podem ser vistas por meio do comando `kind version --help` sendo elas:

- **-q**, **--quiet** -> Mostra somente a versão do Kind sem nenhuma informação a mais.

---

### Exemplos

Ex:
```bash
kind version
```

Ex2.:
```bash
kind version -q
```
