### Descrição

O **kind get clusters** lista os kind clusters existentes pelo nome.

---

### Sintaxe

kind **get clusters** [OPTIONS]

---

### Opções

As opções podem ser vistas por meio dos comandos `kind get --help`, `kind get clusters --help` sendo elas:

- **-q**, **--quiet** -> Silencia toda a saída de erro padrão (stderr).

---

### Exemplos

Ex:
```bash
kind get clusters
```

Ex2:
```bash
kind get clusters -q
```
